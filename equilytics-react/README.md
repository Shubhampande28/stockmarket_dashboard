# Equilytics React UI

Premium React + Tailwind stock screener prototype.

## Run Locally

```bash
cd equilytics-react
npm install
npm run dev
```

## Structure

- `src/components/Navbar.jsx`
- `src/components/Sidebar.jsx`
- `src/components/BottomNav.jsx`
- `src/components/FilterPanel.jsx`
- `src/components/StockTable.jsx`
- `src/components/StockCard.jsx`
- `src/components/Sparkline.jsx`
- `src/pages/ScreenerPage.jsx`
- `src/data/stocks.js`

The current data is dummy data, ready to be replaced with your live stock API.
